# Jogo "Atire no Alvo" + Automação com PyAutoGUI

Este repositório contém dois scripts em Python com propósitos diferentes, mas igualmente interessantes:

1. **Jogo "Atire no Alvo"**: Um jogo simples desenvolvido com Pygame, onde o objetivo é movimentar um canhão e atingir um alvo que se move na tela.
2. **Automação com PyAutoGUI**: Um script de automação para enviar mensagens automaticamente no WhatsApp Web utilizando as bibliotecas `pyautogui` e `pyperclip`.

---

## Jogo "Atire no Alvo"

### Descrição
O jogo foi desenvolvido com **Pygame** e desafia o jogador a movimentar um canhão e atingir um alvo que se desloca verticalmente. Cada vez que o canhão atinge o alvo, o jogo reinicia o alvo em uma nova posição.

### Funcionalidades
- Movimentação do canhão com as setas esquerda/direita.
- Alvo se move automaticamente de cima para baixo.
- Detecção de colisão entre o canhão e o alvo.

### Requisitos
- Python 3.x
- Biblioteca **Pygame** instalada.
  ```bash
  pip install pygame
